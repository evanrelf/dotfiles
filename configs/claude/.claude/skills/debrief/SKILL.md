# Debrief

Before the session ends, raise anything that will still matter after it ends,
whatever happens to the work done in it.

The most valuable items are usually things you noticed in passing, outside the
task: stale docs, suspicious config, latent bugs, workarounds that no longer
work. Check a claim before raising it.

Saying nothing is a normal, good answer. Never pad. Lead with the strongest
item.

Do raise:

- Problems you noticed in passing, outside the task: suspicious config, latent
  bugs, workarounds that may no longer work.
- Docs, comments, or task lists that this session made stale or showed to be
  wrong.
- Work left in a broken or unsafe state that has to be finished or reverted.
- Open questions only the user can answer that block future work.

Don't raise:

- Critiques of how the session went (process, pacing, what you'd do
  differently), especially for work the user is abandoning.
- Suggestions that only apply to this session's particular task.
- Ephemeral state: uncommitted changes, unanswered nits, cleanup you already
  did.
